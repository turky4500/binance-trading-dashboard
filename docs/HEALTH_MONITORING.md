# 🩺 دليل مراقبة صحة النظام — Health Monitoring

ثلاث طبقات مراقبة متكاملة — تعرف أي عطل قبل أن تسأل.

## 1) داخل اللوحة — تبويب Market

تبويب **Market (السوق)** يعرض صحة الأنابيب مباشرة:

- **اتساع السوق التاريخي**: رسم بياني لنسبة العملات فوق EMA50 عبر الزمن (نطاق 35–60 مظلل) + خط سعر BTC — يُسجَّل كل دورة تحليل في `data/breadth_history.json`.
- **صحة الأنابيب (آخر 24 ساعة)**: عدد الدورات، أطول انقطاع بين دورتين، ومتوسط زمن الدورة (من `data/update_log.json`).
- **سجل التشغيل**: آخر 12 دورة بتوقيتها ومدتها — ترى فورًا إذا توقفت الدورات.

> التفسير العملي: إن رأيت "أطول انقطاع 90+ دقيقة" فهذا يعني أن GitHub أجّل الدورات (أو أن cron-job.org بحاجة فحص). إن كان الانقطاع < 20 دقيقة فكل شيء سليم.

## 2) UptimeRobot — مراقبة خارجية مجانية (اختياري، ~دقيقتان)

يراقب أن الموقع نفسه حي حتى وأنت نائم، ويخطرك ببريد/تنبيه عند أي انقطاع:

1. سجّل في https://uptimerobot.com (خطة مجانية تكفي)
2. **+ New monitor** ← نوع **HTTP(s)**
3. **URL:** `https://turky4500.github.io/binance-trading-dashboard/`
4. **Monitor interval:** 5 دقائق
5. **Keyword:** فعّل Keyword monitoring واكتب `BINANCE TRADING DASHBOARD`
   (هذا يتحقق أن الصفحة الفعلية تُحمَّل وليس صفحة خطأ)
6. فعّل التنبيهات (Email + Pushover/Telegram حسب خطتك) ثم **Create**

> ملاحظة: مراقب الكلمة يتحقق من توفر الصفحة. للتحقق من حداثة البيانات نفسها، افتح تبويب Market في اللوحة (الطبقة 1) — أو فعّل إشعارات الفشل في الطبقة 3.

## 3) إشعار فشل الأنابيب عبر Telegram (اختياري)

أضيفت خطوة في الـ Workflow: إذا فشلت أي دورة لأي سبب، تُرسل رسالة:

```
⚠️ Pipeline FAILURE
Repo: ...
Run: https://github.com/.../actions/runs/123
```

للتفعيل: أضف السيكرتين `TELEGRAM_BOT_TOKEN` و`TELEGRAM_CHAT_ID` في
**Settings → Secrets and variables → Actions** (تعمل الخطوة تلقائيًا عند وجودهما).
الرسالة تصل فور فشل الدورة — قبل أن تلاحظ أي شيء في اللوحة.

---

## ماذا تفعل عند تنبيه؟

| المؤشر | الاحتمال | الإجراء |
|---|---|---|
| أطول انقطاع 20–90 دقيقة | GitHub أجّل الجدولة (طبيعي أحيانًا) | لا شيء — cron-job.org يعوض، والعداد يعرض "مزامنة" |
| انقطاع > 3 ساعات + رسالة فشل Telegram | عطل حقيقي | افتح تبويب Actions وراجع آخر دورة فاشلة |
| UptimeRobot ينبه + اللوحة لا تفتح | مشكلة GitHub Pages | راجع Settings → Pages في المستودع |
