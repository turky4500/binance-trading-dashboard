كيف يعمل النظام

كل 15 دقيقة يقوم نظام GitHub Actions بجلب بيانات البورصة الحية من Binance، وفحص مئات أزواج USDT، وتحليل فني متعدد الإطارات الزمنية (15 دقيقة / 1 ساعة / 4 ساعات / يومي: EMA 20/50/200، RSI، MACD، ATR، VWAP، هيكل السوق، كشف الاختراق)، وحساب مناطق الدخول ووقف الخسارة والأهداف، وتصنيف كل خطة من 100، وتتبع دورة حياة الفرص المنشورة، وحفظ النتائج كـ JSON.

لوحة التحكم هي صفحة ثابتة تقرأ ملفات JSON هذه — لا شيء مخترع، ولا نموذج ذكاء اصطناعي ينتج أي سعر أو مستوى، والنظام لا يضع أبداً أي صفقات. هو 100% للقراءة فقط.

الصفحة تتحدث تلقائياً: عد تنازلي يُظهر الوقت المتبقي للدورة التالية، والبيانات الجديدة تُسحب وتُعرض بدون إعادة تحميل يدوية، ويمكنك التبديل بين الأوضاع الداكنة والفاتحة.

تداول العملات الرقمية ينطوي على مخاطر عالية. هذه الأداة لأغراض معلوماتية وتعليمية فقط وليست نصيحة مالية.
