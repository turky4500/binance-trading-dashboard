How this system works

Every 15 minutes a GitHub Actions workflow pulls live public Binance market data, screens hundreds of USDT spot pairs, runs deterministic multi-timeframe technical analysis (15m/1h/4h/1d: EMA 20/50/200, RSI, MACD, ATR, VWAP, structure, breakout detection), computes entry zones, stop losses and targets, scores each plan out of 100, tracks the lifecycle of published setups, and commits the results as JSON.

The dashboard is a static page that reads those JSON files — nothing is invented, no LLM produces any price or level, and the system never places orders. It is 100% read-only.

The page updates itself automatically: a countdown shows the time left until the next data cycle, fresh data is pulled and rendered without a manual reload, and you can switch between dark and light themes.
